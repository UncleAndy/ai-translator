# Примеры конфигураций

| Файл | Для чего |
|---|---|
| `config.all.toml` | Справочник: все параметры с описанием и значениями по умолчанию. Все приёмники, кроме консоли, выключены, поэтому проверка проходит без ключа и оборудования. |
| `config.dev.toml` | Разработка: микрофон, консоль, страница большого экрана и двуязычный транскрипт. |
| `config.offline.toml` | Без сети: консоль и файл; годится для прогона `script`. |
| `config.stream.toml` | Трансляция: экран, титры, вебхук и виртуальное звуковое устройство (два последних выключены). |

Проверить любой из них, ничего не запуская:

```sh
ai-translator check --config examples/config.all.toml
```
